# TermAI
Agente Autônomo

## Notas de Lançamento

### Atualização Recente
- **Suporte a Reasoning**: Agora o agente pode processar e exibir o pensamento interno (reasoning) do modelo antes de gerar a resposta final.
- **Melhorias no Stream**: A interface de usuário (UI) foi atualizada para exibir o reasoning em um bloco visualmente distinto durante o streaming.
- **Configuração Centralizada**: Adicionado suporte para `config.json` na pasta de configuração do usuário (`~/.TermAI/config.json`).
- **Compatibilidade**: Refinamentos no código para melhor suporte a diferentes modelos e endpoints via OpenRouter.
