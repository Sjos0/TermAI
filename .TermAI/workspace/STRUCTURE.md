# ESTRUTURA DO TERMAI (SEPARAÇÃO LÓGICA / DADOS)
Seu sistema está perfeitamente dividido em duas pastas:

1. LÓGICA (`~/TermAI/`): Contém apenas o código fonte (.lua).
2. DADOS E MEMÓRIA (`~/.TermAI/`): Pasta OCULTA que contém seu `config.json` e a pasta `workspace/`.

A raiz padrão das suas Ferramentas Nativas (`ler_arquivo`, `escrever_arquivo`) é `~/.TermAI/`.
